English (TÜRÇE İÇİN AŞAĞI KAYDIRIN)

WOXION IP Tracker is a modern, cyberpunk-themed IP intelligence panel built with Python. It allows you to:

Lookup IP addresses and get detailed information including ISP, organization, ASN, city, region, country, ZIP code, timezone, latitude & longitude. Open the IP location directly on Google Maps with one click. Enjoy a sleek purple & black cyberpunk interface. Access a professional panel with an integrated results console.

This tool is perfect for network enthusiasts, cybersecurity learners, or anyone interested in IP tracking. It uses the free IP-API for geolocation.

Features:

- IP geolocation & network intelligence
- Integrated Google Maps viewer
- Error handling & clear console output
Installation:

pip install customtkinter requests

Usage:

Run python woxion_ip_tracker.py Enter an IP address and click SCAN To see the location on Google Maps, click OPEN MAP
